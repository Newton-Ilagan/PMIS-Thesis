# Project Management Information System (PMIS)

A desktop-based Project Management Information System developed as a capstone project for Module Pro Furniture and Fixture.

## Overview

This system was developed to improve how projects are managed by replacing manual record-keeping with a centralized desktop application. It allows users to organize project information, monitor project progress, manage client records, and track project status in one place.

## Features

- Dashboard
- Project Creation
- Project Management
- Analytics
- User Management
- Notifications
- Settings
- Backup and Restore

## Technologies Used

- C#
- Windows Forms
- SQLite
- Visual Studio
